# Отслеживаемые участники и отчёты Discord

## Цель

Добавить в существующую админку отдельный раздел «Отслеживание». Администратор выбирает участников Discord-сервера по имени, задаёт каждому индивидуальный рабочий график и настраивает текстовый канал. Бот по slash-команде публикует в этот канал статистику выбранных участников и их совместного нахождения в одном голосовом канале.

## Границы

- Существующие whitelist, blacklist, правила, mute levels и pair stacking не меняются.
- Голосовые сессии по-прежнему пишутся в `voice_sessions`; обработчик Discord-событий не дублируется.
- Отчёт создаётся только по явному вызову администратора, без фоновой рассылки.

## Модель данных

### tracked_members

Отдельная таблица отслеживаемых участников:

- `discord_id` — уникальный Discord ID;
- `username` — последнее известное отображаемое имя;
- `is_active` — участвует ли в расчётах;
- `work_days` — массив дней недели, по умолчанию Пн–Пт;
- `work_start` / `work_end` — границы рабочего дня, по умолчанию 09:00–18:00;
- `timezone` — по умолчанию `Europe/Moscow`;
- временные метки создания и обновления.

### tracking_settings

Одна запись конфигурации с `report_channel_id` — каналом Discord для публикации отчётов.

## Расчёты

Для каждого активного отслеживаемого участника отчёт считает за выбранный период:

- суммарное время в голосовых каналах;
- число голосовых сессий;
- время, попавшее в его персональное рабочее окно.

Незакрытая сессия учитывается до времени построения отчёта. Временные метки хранятся в UTC, а рабочее окно интерпретируется в часовом поясе участника.

«Стак» — пересечение двух сессий активных отслеживаемых участников при одинаковом `channel_id`. Для каждой пары отчёт суммирует длительность пересечений; переход между каналами естественно делит пересечение на отдельные интервалы.

## API и админка

Новый маршрут фронтенда «Отслеживание» использует уже существующий поиск участников `/api/members` и не требует ручного Discord ID.

Экран включает:

- выбор текстового канала для отчётов;
- поиск и добавление участников сервера;
- таблицу отслеживаемых участников;
- редактирование индивидуальных дней, времени и часового пояса;
- удаление или деактивацию участника;
- предпросмотр отчёта через API.

Бэкенд добавляет CRUD API для `tracked_members`, API настроек канала, список текстовых каналов текущего сервера и API предпросмотра отчёта.

## Discord-команда

Новая администраторская команда: `/tracking report`.

- `period`: `today`, `week` или `month`; значение по умолчанию — `today`;
- бот проверяет настроенный канал и публикует туда embed;
- вызывавший администратор получает только ephemeral-подтверждение;
- embed содержит персональную статистику и блок со стаками: пара, канал и длительность вместе.

## Ошибки и доступ

- Все API требуют существующей авторизации админки.
- Slash-команда доступна только администраторам.
- При отсутствии выбранного канала, участников или доступа бота к каналу возвращается понятное сообщение без публикации.
- Участники, покинувшие сервер, остаются в исторических расчётах по Discord ID, но в интерфейсе отмечаются как недоступные.

## Проверка

- Unit-тесты рабочего времени, включая границы окна и МСК.
- Unit-тесты пересечений сессий в одном и разных каналах.
- Тесты репозитория и API CRUD/предпросмотра.
- Тест slash-команды на выбор периода, публикацию в настроенный канал и ошибки конфигурации.
- Playwright-проверка нового экрана: поиск, добавление, редактирование графика и выбор канала.
